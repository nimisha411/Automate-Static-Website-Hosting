# 🚀 Automate Static Website Hosting using AWS S3 and Python boto3

## 📌 Project Overview
This project automates static website hosting on Amazon S3 using Python and boto3 SDK.

The script automatically:
- Creates an S3 bucket
- Uploads website files
- Enables static website hosting
- Makes the website publicly accessible

---

## 🧰 AWS Services Used
- Amazon S3
- AWS IAM
- boto3 SDK
